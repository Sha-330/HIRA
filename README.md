# HIRA - Health Index & Result Analyzer

## 📌 Overview
HIRA (Health Index & Result Analyzer) is an AI-driven healthcare system designed to enhance the accuracy and efficiency of medical assessments. It integrates deep learning-based medical image analysis and condition-based health evaluations to provide real-time insights into patient health. 

## 🚀 Features
- **Medical Image Analysis**: Uses a custom CNN model to analyze X-rays, MRI, and CT scans.
- **Text-Based Health Analysis**: Processes blood and urine test reports using OCR.
- **Automated Report Generation**: Provides comprehensive health reports.
- **Early Disease Detection**: Enables proactive medical interventions.
- **Web-Based Interface**: User-friendly platform for report submission and result retrieval.

## 🏗️ Architecture
HIRA consists of the following core components:
- **Custom CNN Model**: For medical image classification.
- **Watershed Segmentation**: For feature extraction in image-based diagnostics.
- **LangChain Agent**: For extracting text from PDFs.
- **Tesseract OCR**: For text recognition from medical documents.

## 🔬 Development Overview
### 1️⃣ Text-Based Results Processing
- Extracts health indicators from blood and urine test reports.
- Applies condition-based analysis to generate health reports.
- Cross-references results with predefined medical conditions.

### 2️⃣ Image-Based Results Analysis
- Analyzes MRI, CT, and X-ray images.
- Detects anomalies using a trained CNN model.
- Provides heatmap visualizations for precise diagnosis.

### 3️⃣ Website & User Interface
- Built with **HTML, CSS, and JavaScript**.
- Includes pages for **index, login, file upload, and result viewing**.

## 📊 Sample Results
HIRA automates medical data analysis to provide accurate diagnostics. Heatmap visualizations and structured text reports assist healthcare professionals in making informed decisions.

## 🎯 Future Scope
- Integration with electronic health records (EHR) systems.
- Expansion to additional medical imaging modalities.
- AI model refinement for higher accuracy and reliability.
